# Редизайн фронтенда «Маяк» — дизайн-документ

Дата: 2026-07-27
Статус: утверждён пользователем, готов к планированию реализации

## Контекст

«Маяк» — система управления звуковыми оповещениями (школьные звонки, тревоги,
плановые сценарии). Аудитория — дежурные диспетчеры и администраторы,
работающие с панелью в оперативном режиме. Текущий UI (React 19 + Vite +
Tailwind 4, `web/`) визуально нейтрален: тёмный фон, стандартный синий акцент,
плоские карточки — типичный generic admin-шаблон без связи с образом «маяка».

Задача: сделать выразительный редизайн всего фронтенда (все страницы + общая
дизайн-система), сохранив текущую функциональность и структуру компонентов.
Портфолио-оформление репозитория — отдельная задача, идёт после утверждения
и реализации редизайна.

## Охват

Все страницы и общие компоненты в `web/src`:
`pages/login.jsx`, `pages/Dashboard.jsx`, `pages/Alarms.jsx`,
`pages/Devices.jsx`, `pages/PlannedAlerts.jsx`, `pages/Settings.jsx`,
`components/Navbar.jsx`, `components/SystemStatus.jsx`,
`components/AlarmControlPanel.jsx`, `components/ChangeDutyPanel.jsx`,
`components/ui/*`, `components/Alarms/*`, `components/Alerts/*`,
`components/Devices/*`, `components/Settings/*`, а также
`assets/styles/index.css` (токены темы).

Структура страниц и компонентов не меняется (те же блоки, та же навигация,
те же формы) — меняется визуальный язык: цвет, типографика, скругления,
статус-индикация, layout экрана логина.

## Дизайн-система

### Цвет

Тёмная тема — приоритетная (сохраняется как тема по умолчанию), светлая —
поддерживается тем же токенами с другими значениями. Отказ от нейтрального
«тёмно-серый + синий» в пользу метафоры «ночное море + тёплый луч маяка».

Тёмная:

| Токен | HEX | Роль |
|---|---|---|
| `--bg` | `#0A0F16` | фон приложения (глубокий тёмно-синий, не чёрный) |
| `--surface` | `#111925` | панели, карточки |
| `--surface-2` | `#182130` | вложенные блоки, инпуты |
| `--surface-3` | `#212B3A` | ещё один уровень вложенности (было в старой теме) |
| `--border` | `#26323F` | границы |
| `--text` | `#EAF1F5` | основной текст |
| `--text-soft` | `#C3CDD6` | вторичный текст |
| `--text-muted` | `#7C8A96` | приглушённый текст |
| `--beacon` | `#FFB454` | основной акцент («луч маяка»): кнопки, активные состояния, фокус-кольца, ссылки |
| `--beacon-strong` | `#FFA53D` | hover/active состояние акцента |
| `--alarm` | `#FF5C4D` | тревога, деструктивные действия |
| `--safe` | `#34D399` | «всё спокойно», успех |

Существующие статус-цвета (`bg-blue-600` и т.п. на кнопках) заменяются на
токены `--beacon` / `--alarm` / `--safe` вместо жёстко заданных цветов
Tailwind, чтобы тема была согласована во всех компонентах.

### Типографика

Три роли шрифта, self-hosted через `@fontsource` (без внешних CDN — важно
для офлайн/docker-деплоя без доступа в интернет):

- **Display** (`--font-display`): `Big Shoulders Display` — узкий, высокий,
  индустриальный шрифт для заголовков, названия «Маяк», заголовков секций.
  Ассоциация с башней маяка / сигнальным щитом.
- **Body** (`--font-body`): `Inter` — нейтральный, читаемый, для основного
  интерфейса и плотных форм/таблиц.
- **Mono** (`--font-mono`): `IBM Plex Mono` — для времени, ID устройств,
  логов, статус-кодов; подчёркивает эстетику «пульта диспетчера».

### Сигнатурный элемент — «пульс маяка»

Анимированный статус-индикатор (используется в `SystemStatus` и
`AlarmControlPanel`, где статус уже отображается сегодня — редизайн, а не
новая функциональность):

- ожидание/норма — медленная спокойная пульсация `--beacon`
- активная тревога — быстрая пульсация `--alarm`
- «всё чисто» / подтверждённое состояние — спокойный `--safe`

Реализуется как CSS radial-gradient/box-shadow пульсация (`@keyframes`),
с уважением `prefers-reduced-motion: reduce` (статичное кольцо без анимации).
Тот же приём в приглушённом виде используется как фоновое свечение на экране
логина (статичный градиент, не анимация).

### Layout

**Login** (`pages/login.jsx`): вместо центрированной карточки на пустом фоне —
асимметричный split-экран. Слева — брендовая панель (логотип, «Маяк»,
подпись, статичное свечение-луч на фоне), справа — форма входа на
`--surface`. На узких экранах брендовая панель сворачивается в компактную
полосу сверху, форма — под ней (мобильная адаптация обязательна).

**Внутренние страницы** (Dashboard, Alarms, Devices, PlannedAlerts, Settings):
структура остаётся (Navbar сверху + карточки-панели) — она функционально
работает под «пульт управления». Меняются:
- токены цвета/типографики по всем компонентам
- скругления — чуть жёстче, приборная эстетика вместо мягкого SaaS-вида
  (например `rounded-md`/`rounded-lg` вместо `rounded-xl`/`rounded-2xl`
  там, где сейчас чрезмерно мягко)
- акценты кнопок/фокуса/ссылок — `--beacon` вместо `blue-600`
- статус-индикаторы получают «пульс маяка»

## Не входит в объём

- Изменение бизнес-логики, API, роутинга, структуры компонентов.
- Портфолио-оформление репозитория (README, скриншоты, стиль а-ля «кузня») —
  отдельная задача после завершения и утверждения редизайна.
- Мобильное приложение / прошивки устройств (`devices/`) — вне охвата.

## Тестирование / проверка

- Визуальная проверка обеих тем (dark/light) на Login и на каждой странице
  через локальный dev-сервер (`npm run dev` в `web/`), скриншоты до/после.
- Проверка адаптивности (мобильная ширина) для Login и Dashboard.
- Проверка `prefers-reduced-motion` для пульсации.
- `npm run build` в `web/` проходит без ошибок (Tailwind/Vite).
